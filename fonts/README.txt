PEAPS - local fonts (works without internet)
===========================================

Put these two files in this folder (same name, same case):

  DMSans-Variable.ttf
  Manrope-Variable.ttf

How to get them (free, SIL Open Font License):
  1. Go to https://fonts.google.com and search for "DM Sans", then click "Get font" > "Download all".
  2. In the downloaded zip, take the variable font file (its name contains "VariableFont",
     e.g. "DMSans-VariableFont_opsz,wght.ttf") and rename it  DMSans-Variable.ttf
  3. Do the same for "Manrope": take "Manrope-VariableFont_wght.ttf" and rename it  Manrope-Variable.ttf
  4. Copy both files here.

Until the files are present, the browser uses the fonts installed on the computer, or Arial.
